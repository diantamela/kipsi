Coconut Purchase Customization

PT Coco Murni Prima Jaya

Customisasi modul Purchase untuk perusahaan pengolahan kelapa.

Features

  • Supplier Management: Data CV pemasok dengan kontak, HP, dan alamat lengkap.
  • Delivery Tracking: Data sopir, nomor HP sopir, dan nomor kendaraan.
  • Coconut Receiving: Nomor penerimaan, tanggal masuk, jam masuk, berat total.
  • Quality Sorting: Sortir kelapa cungkil mesin dan manual dengan validasi otomatis.
  • Inventory Integration: Auto-create stock picking saat konfirmasi penerimaan.
  • Reporting: Cetak slip penerimaan kelapa.

Technical Details

  • Model: coconut.supplier.receipt
  • Dependencies: purchase, stock, product
  • Sequence Format: RMP/YYYY/MM/XXXX
